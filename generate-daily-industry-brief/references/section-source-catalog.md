# Section source and query catalog

Read this reference for every live generation run. It defines the intended breadth of each standard section and the recurring custom-interest profiles used by this brief. Names are discovery targets, not endorsements.

## Acceptance rule

Use **section-first retrieval**:

1. An event qualifies when it is genuinely about the selected section and has a fresh, verifiable source. A construction/AEC connection improves ranking but is not a universal admission requirement.
2. Apply a construction-only filter only to sections whose definition is inherently construction-specific, such as `sourcing`, `employment`, `informatization`, and `construction-tech`. Even there, accept directly relevant labour, software, equipment, materials and project evidence without requiring the literal word `建筑`.
3. Broad discovery terms may be used first, but the eight business rows (`fintech`, `sourcing`, `matching`, `employment`, `overseas`, `leadership`, `enterprise`, `capital`) must pass the construction-anchor gate in `industry-anchor-policy.md` before admission. `extended` must cover its five prescribed research/deep-reading tracks and retain only construction-ecosystem material.
4. `industry_scope` is a ranking context, not a hidden exclusion rule. Never shrink “半导体” to semiconductor-factory EPC, “政府宏观” to housing departments, or “数科” to construction-only finance unless the user explicitly asks for that narrower scope.

## Per-section search lanes

### Open source-matrix rule

Named organizations are seed examples, never a closed whitelist. For every selected row build an applicable source matrix from: central government/regulator, provincial or municipal authority, exchange/registry/procurement platform, association/research publisher, head national or financial media, specialist vertical media, central SOE, local SOE, private or listed company, project owner/counterparty and foreign original source. Mark each family `applicable`, `checked`, `not applicable` or `failed` in the ledger. A row cannot close merely because the named seed organizations were quiet.

After the seed pass, execute an **actor-expansion pass**: extract organizations, counterparties, owners, subsidiaries and regions from current results, then search those actors' official newsrooms/disclosures and one independent source. Persist newly reliable actors in the run ledger as `dynamic_source_additions`; do not silently promote them to a permanent endorsement list. In particular, company-oriented rows must cover both central SOEs and representative local SOEs when applicable. The same rule applies across all boards, not only `overseas`.

### Publication and event time rule

Record four separate values whenever available: original first-publication time, original update time, event time and retrieval time. The window basis is the event time only when the original record explicitly dates the event; otherwise use the original first-publication time. Search-result dates, repost dates and page-update timestamps never establish eligibility. Run the strict rolling 24-hour pass first. Only a row with no qualified primary-window item may run its own 24–48-hour fallback. Anything older than 48 hours is background evidence and cannot become a story card.

For each row, run these lanes in order and retain 2–3 strong, independent items when the verified window supplies them. If fewer than two qualify, complete the low-yield expansion lane and record the specific evidence-based stop reason.

1. **Field lane:** the section/custom label plus fresh event verbs (`发布`, `公告`, `签约`, `中标`, `投产`, `融资`, `政策`, `报告`).
2. **Source/actor lane:** the named official families or companies above plus the run date/window.
3. **Official-record lane:** inspect a relevant regulator, exchange, registry, procurement/project platform, company IR index or other primary-source listing.
4. **Business-intersection lane:** combine the field with construction, infrastructure, enterprise operations or the configured `industry_scope` to improve relevance; it does not permit duplicate rendering in another section.
5. **Low-yield expansion lane:** when a custom row has zero or one formal story, search one independent national news, specialist vertical or reliable mirror route before finalizing.

Classify candidates with the A/B/C/D policy in `topics.md`. Assign every retained event to exactly one strongest section; record overlapping row matches as excluded leads and continue independent discovery for those rows.

The fourth lane enriches the brief; it does not erase valid results from the first three lanes. Evidence discovered for another row may provide a lead, but it never replaces these custom-row checks or becomes a duplicate card.

## Direct-network fallback when no search tool exists

When a host can access the public Internet but has no dedicated search tool, use `network-retrieval-playbook.md` rather than asking for an external feed. For each selected row, open its named Tier 1/official route in the table above and then one independent route below. The Agent may use a browser, command-line/native HTTP, RSS, sitemap, site-native search, public API or an accessible public search-results page.

| Board group | Official index/feed route | Independent discovery route |
|---|---|---|
| 数科、企业经营、投融资、高管观点 | regulator, exchange/CNInfo, company IR/newsroom, bond/rating disclosure | named financial media, disclosure mirror, counterparty or event organizer |
| 寻源、撮合、用工 | government procurement/public-resource, project owner/contractor, HRSS/public employment lists | enterprise procurement/newsroom, association/chamber or public employment/project platform |
| 海外、政府宏观、行业数据、标准规范、绿色低碳 | central/local government or regulator publication list, statistics/standard/energy data index | provincial/municipal/project-execution channel, established financial or vertical publisher |
| AI、建筑软件、建筑科技 | vendor/research institute/government technology newsroom or project-owner release | customer/counterparty release, specialist technology/industry publisher or association |
| 拓展阅读与自定义兴趣 | exact field's regulator, registry, exchange, association, company or project listing | field-specific vertical/financial publisher, counterparty, site-native search or public search page |

Record the actual reachable URL family and transport in the ledger. A failed first official URL requires an alternate endpoint, RSS/print/listing page, counterparty or named Tier 2 route before the row can be called limited. An absence of `webSearch`, a paid API, or a preconfigured RSS aggregator is never a sufficient stop reason.
